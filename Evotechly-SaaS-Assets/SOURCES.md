## How to add a source later

1. Official URL only.
2. Read the current EULA the same day you download.
3. Fill every column. If two pages disagree, status = `MANUAL` + **REQUIRES LICENSE REVIEW**.
4. Do not set `downloaded: true` in the registry until the file is on disk and the license file is saved next to it.
