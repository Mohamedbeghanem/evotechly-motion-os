# Install Evotechly Motion OS in After Effects

One file. No Node.

## File

`ae/Evotechly Motion OS.jsx`

## Install

1. Quit After Effects.
2. Copy the JSX into **Scripts/ScriptUI Panels**.
3. Open AE → **Window → Evotechly Motion OS**.

## Phase 0 use

1. **Demo comp** builds Title + Card 1 + Card 2 + CTA.
2. **Scan**. Rows: READY / UNNAMED / SKIP.
3. Select UNNAMED → pick role → **Rename** (or double-click).
4. **Apply motion**. Comp markers named `EVO …` if the checkbox is on.

Never keyed: cameras, lights, locked layers, names containing `EVO_SKIP`.
