# Install panel v0.32

`ae/Evotechly Motion OS.jsx` on main is the v0.32 Reliability panel (~297 KB).

Also copy `ae/SaaS Demo Tools.jsx` into `Scripts/ScriptUI Panels` for cursor + click, depth reveal, stagger, carousel, glass, wipe, and proximity. That companion does not replace the main panel.

Golden comps: File → Scripts → Run Script File… → `ae/Seed Golden Project.jsx`. See `docs/QUICK_START.md` and `docs/SAAS_DEMO_KIT.md`.
