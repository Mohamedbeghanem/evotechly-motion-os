# Install Evotechly Motion OS Ultimate 2.0 (v0.32 panel + companions)

`ae/Evotechly Motion OS.jsx` on main is the v0.32 Reliability panel (~297 KB). Ultimate **2.0.0** ships that panel plus three companions. Do not stub the 297 KB file.

Install **all four**:

1. `ae/Evotechly Motion OS.jsx` — **Window → Evotechly Motion OS**
2. `ae/SaaS Demo Tools.jsx` — **Window → SaaS Demo Tools / Motion OS Hub** (Home seed, SaaS engines including Flowing Text and Coloured Reveal, Kit Hub official URLs)
3. `ae/Caption Style Tools.jsx` — **Window → Caption Style Tools** (P1c keyword color + in/out; separate companion)
4. `ae/Seed Golden Project.jsx` — **File → Scripts → Run Script File…** or Hub → Home → Seed

Copy the first three into `Scripts/ScriptUI Panels`. Copy Seed into `Scripts` (keep a copy next to the Hub for Home → Seed). None of the companions replace the main panel.

See `docs/QUICK_START.md`, `docs/SAAS_DEMO_KIT.md`, and `docs/CAPTION_STYLE.md`.
