# Install panel v0.32

`ae/Evotechly Motion OS.jsx` on main is the v0.32 Reliability panel (~297 KB).

Also copy `ae/SaaS Demo Tools.jsx` and `ae/Caption Style Tools.jsx` into `Scripts/ScriptUI Panels`. Hub is Home seed + SaaS engines (including Flowing Text and Coloured Reveal) + Kit Hub official URLs. Caption Style is P1c keyword color + in/out (separate companion). Neither replaces the main panel.

Golden comps: File → Scripts → Run Script File… → `ae/Seed Golden Project.jsx`. See `docs/QUICK_START.md` and `docs/SAAS_DEMO_KIT.md`.
