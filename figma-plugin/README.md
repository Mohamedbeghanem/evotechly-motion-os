# Evotechly Figma plugin

Turn a frame into evotechly.motion.design.v1 JSON for the After Effects panel.

## Install (once)

1. Figma desktop (not the browser).
2. Plugins → Development → Import plugin from manifest…
3. Pick figma-plugin/manifest.json from this repo.
4. Do not delete that folder.

## Export

1. Select the frame.
2. Run Evotechly Motion OS.
3. Copy JSON.
4. AE panel → Paste JSON or Import JSON.
5. Scan → Apply.

Names that map: PricingCard, Feature tile, PrimaryButton, HeroTitle, AppScreenshot, Topbar, KPI.
Prefix EVO_SKIP to omit a layer.
